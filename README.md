# PETRO PALACE — site vitrine statique

Démonstration commerciale non officielle. HTML, CSS et JavaScript natifs : **aucune installation, aucun npm, aucun build**.

## Fichiers
- `index.html` : structure et contenu
- `style.css` : responsive et animations
- `script.js` : filtres, galerie, avis, réservation fictive, navigation

## Lancer en local
Ouvrir `index.html` dans un navigateur. Une connexion Internet est nécessaire pour charger les polices et les photos illustratives distantes.

## Publier sur GitHub Pages
1. Créer un dépôt public `petro-palace` sur GitHub.
2. Envoyer les trois fichiers `index.html`, `style.css` et `script.js` **à la racine du dépôt** (et ce README si souhaité).
3. Dans **Settings > Pages > Build and deployment**, sélectionner **Deploy from a branch**, puis **main** et **/(root)** ; enregistrer.
4. Consulter `https://VOTRE_IDENTIFIANT.github.io/petro-palace/` après publication.

## Avant une mise en ligne officielle
- Obtenir l'accord du propriétaire.
- Remplacer les photos et les plats illustratifs par des contenus autorisés et validés.
- Confirmer le téléphone, les horaires et les informations commerciales.
- Brancher un vrai système de réservation si nécessaire.

Le formulaire ne stocke ni n'envoie aucune donnée ; il affiche uniquement un récapitulatif local. Les photos sont chargées depuis Unsplash et peuvent nécessiter une vérification des conditions d'utilisation avant une exploitation commerciale.
